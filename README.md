# Proper Pizza Komoran – Webfaqja

Webfaqja zyrtare e Proper Pizza në Komoran: menyja me çmime, ofertat, kafja Lavazza,
shporta e porosisë me ekstra/shënime dhe dërgimi i porosisë në WhatsApp me lokacion.

- `index.html` – e gjithë faqja (HTML, CSS, JS në një skedar)
- `img/` – fotot dhe videot

## Publikimi
Netlify: Import from Git → zgjidh këtë repo → Publish directory: `.` (pa build command).

## Ndryshimi i çmimeve
Te `index.html`, kërko `var PIZZAS=`, `SAND`, `DRINKS`, `HOT`, `EXTRAS`, `COMBOS`.
